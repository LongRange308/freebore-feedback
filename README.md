# Freebore — Beta feedback

Public feedback page for testers of the Freebore app (Google Play closed test).

Feedback URL: https://longrange308.github.io/freebore-feedback/

Messages go through the form (FormSubmit, with attachments up to 10 MB); the address is not published on the page, only FormSubmit's random alias.

Privacy policy: https://longrange308.github.io/freebore-privacy/
